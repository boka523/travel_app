# Travel App

[Live Demo] (https://your-live-demo-url.com)

A simple and practical travel planning app that helps users calculate trip costs clearly and avoid hidden expenses.

## Project Description

Travel App allows users to estimate the total cost of a trip by adding transportation, accommodation, food, activities and other travel-related expenses. It is designed to make travel budgeting simple, transparent and easy to manage. Travel App is a lightweight web application focused on helping travelers plan their budget before a trip. The project emphasizes clarity, cost awareness and a clean user experience.

## Usage

1. Open the app in your browser.
2. Enter your travel details.
3. Add your expected expenses.
4. Review the total estimate and adjust your plan.

### Techniques and Components

This project includes the following common web development techniques and UI components:

- Expense input form
- Category-based cost breakdown
- Dynamic total calculation
- Summary display
- Responsive layout for desktop and mobile

## Features

- Estimate total travel costs
- Organize expenses into categories
- Calculate totals instantly
- Make travel budgeting easier
- Reduce the chance of unexpected expenses

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Framework: React
- Styling: Custom CSS
- Build Tool: Vite
